# Evidence and analysis definitions

The prepared extended genome contains reference sequences and appended nonreference contigs. Reference/guide annotation contig names are checked against that FASTA before execution. HISAT2 uses --dta. Sample strandedness is either explicitly supplied or estimated from unique read1 overlaps with original-reference exons; ambiguous exon-strand overlaps are excluded and low informative counts are reported.

StringTie assemblies are generated per sample with the supplied guide. Their observed models are merged without inserting guide-only transcripts in the merge command. Only observed models on explicitly designated nonreference contigs are combined with the original reference annotation for fixed-model StringTie -e quantification. featureCounts summarizes paired fragments by exon/gene_id with consistent strandedness; -M and -O are not passed, so multimapping and ambiguous multi-gene assignments are excluded by default.

Candidate selection uses TPM >= configured threshold in at least the configured number of libraries. All isoforms for retained RNA gene IDs are exported, and the longest isoform is reported separately. Isoform lengths are checked against exon-union lengths. All-gene tissue sets are defined independently by arithmetic mean TPM >1 within each tissue; tissue unions contain unique gene IDs.

gffcompare compares observed nonreference RNA models to the supplied nonreference prediction guide. An '=' code is structural support under gffcompare's definitions, not proof of identical full-length sequence or protein function. A 'u' code means unclassified/intergenic relative to that guide and must not be reworded as new intergenic sequence against the original reference genome.

Local DIAMOND BLASTX is optional. Search default: E<=1e-5, ultra-sensitive, <=25 target proteins, one HSP per target. A broad, high-identity match requires identity>=80%, target protein coverage>=80%, aligned length>=50 aa and E<=1e-10; high-identity partial matches meet those criteria except target coverage. Other detected hits remain limited/divergent matches. These categories are descriptive homology evidence, not calibrated probabilities or validations of orthology. Gene families, related copies and possible pseudogenes require additional genomic, ORF and read-mapping analyses. No protein match is not proof of noncoding status.

Optional differential analysis uses integer counts and a two-group edgeR robust quasi-likelihood model after CPM filtering and TMM normalization. All tested genes share a BH multiple-testing family; nonreference rows are then extracted. |log2FC|>1 with raw P<0.05 is exploratory and reported separately from FDR<0.05. This release does not fit paired, batch-adjusted or repeated-measure designs.

R PCA/MDS uses log2(TPM+1), without per-gene variance scaling. MDS selected by the same group comparison is descriptive after selection. A lack of significant candidates yields explicit empty tables/stub notes rather than fabricated points. All sequence- and annotation-based gene names are provisional homolog labels until locus-specific evidence establishes identity and function.
